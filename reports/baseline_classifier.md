# Baseline modulation classifier -- 2 Sep gate

Deterministic decision tree on `abs_C42` and `if_hist_peak_count` only
(`models/features.py::baseline_predict`), fixed thresholds calibrated at
the 10dB measured medians -- not the noiseless theoretical values, which
don't survive real noise (see `models/features.py` module docstring).
This is the number `models/build_dataset.py` + a trained LightGBM model
(3 Sep) has to beat.

Dataset: `models/dataset_train.csv`, 12,600 windows (2,100/class), 6
classes x SNR grid {0,5,10,15,20} dB, generated by
`python -m models.build_dataset`.

## Overall

| Metric | Value |
|---|---|
| Macro-F1 (all SNRs) | **0.520** |
| Accuracy | 0.546 |

## Per-class (all SNRs pooled)

| Class | Precision | Recall | F1 |
|---|---|---|---|
| bpsk | 1.000 | 0.600 | 0.750 |
| 16qam | 0.413 | 0.983 | 0.581 |
| 4fsk | 0.847 | 0.600 | 0.702 |
| 2fsk | 1.000 | 0.491 | 0.659 |
| qpsk | 0.330 | 0.600 | 0.426 |
| 8psk | 0.000 | 0.000 | 0.000 |

**8psk gets exactly zero.** Not a bug: `abs_C42` and `if_hist_peak_count`
are theoretically identical for qpsk and 8psk (both have theoretical
`|C42|=1.00`; qpsk/8psk only separate on `|C40|`, which this baseline is
deliberately not allowed to use). `baseline_predict` always returns
`"qpsk"` for that shared leaf. This is the intended, stated gap the real
model gets to close.

## Per-SNR macro-F1

| SNR (dB) | Macro-F1 |
|---|---|
| 0 | 0.048 |
| 5 | 0.084 |
| 10 | 0.680 |
| 15 | 0.777 |
| 20 | 0.768 |

**Sharp cliff below 10dB, not a bug either.** Two compounding effects,
both measured:

1. `abs_C42` shrinks with noise for every class alike (normalisation
   divides by total signal+noise power; the 4th-order cumulant estimate
   is well-known to be SNR-biased this way). Fixed thresholds calibrated
   at 10dB don't track that shift down to 0-5dB.
2. `if_hist_peak_count` only attempts tone-counting when
   `envelope_variance < 0.05` (gated -- see `models/features.py`, the
   ungated version produces 1-6 spurious peaks on shaped PSK/QAM at this
   window size). At 0-5dB, noise alone pushes FSK's envelope variance
   above that gate often enough to lose the FSK/linear split entirely.

Every stated target in this project is anchored at >=10dB, so this
baseline is graded there: **0.68-0.78 macro-F1 from 10dB up**, comfortably
above chance (1/6 = 0.167) and a real number for the trained model to
beat, not a strawman.

Regenerate: `python -m models.build_dataset` then re-run
`tests/unit/test_features.py::test_baseline_macro_f1_on_training_set`,
which pins these numbers (overall > 0.45, 10dB > 0.6, 0dB < 0.3 -- the
last one guards against silently losing the documented low-SNR gap
without updating this file).
